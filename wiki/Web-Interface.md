# Веб-интерфейс

Весь интерфейс — одна страница. Слева меню из пяти разделов (на узком экране оно
становится строкой сверху): **Торренты**, **Пользователи**, **Трекеры**,
**Настройки**, **Состояние**. Интерфейс работает и на телефоне.

Страница не загружает файлы с других сайтов: всё нужное лежит на вашем сервере.

---

## Первый запуск и вход

- Новая установка открывает форму **«Настройка TorrentMonitor»**: пароль, адрес,
  torrent-клиент. Пароля по умолчанию нет. Подробнее —
  [Первоначальная настройка](Getting-Started#шаг-1--первый-запуск).
- Дальше при входе спрашивается пароль. Отметка **«Запомнить меня на этом устройстве»**
  сохраняет вход на 60 дней. После смены пароля все запомненные входы перестают
  действовать.
- **«Выйти»** — внизу меню.
- Защиту паролем можно выключить и включить в **Настройки → Вход**
  (см. [Настройки](Settings#вход)).

## Что есть на каждой странице

- **«Проверить сейчас»** (справа вверху) — запускает проверку всех тем, не дожидаясь
  расписания. Рядом показано время последней проверки. Пока проверка идёт, вместо
  времени написано «Идёт проверка…»; когда она закончится, страница обновит данные сама.
  Если проверка уже идёт (например, по cron), вторая не запускается.
- Строка **«Доступна версия …»** — появляется, когда вышла новая версия. Ссылка
  «Подробнее» ведёт в раздел «Состояние».
- Числа в меню:
  - у «Пользователи» — сколько найдено новых раздач;
  - у «Трекеры» — сколько трекеров с отслеживаемыми темами остались без учётных данных;
  - у «Состояние» — сколько ошибок (и ещё единица, если доступна новая версия).
- Внизу меню: переключатель темы оформления, ссылка «Справка» (эта вики), «Выйти»
  и номер версии.

### Тема оформления

Светлая и тёмная. По умолчанию — как в системе. Ссылка **«Тема: …»** внизу меню
переключает по кругу: как в системе → светлая → тёмная. Выбор запоминается в браузере.

## Торренты

Список отслеживаемых тем и сериалов. Сверху — те, что обновлялись последними; порядок
можно изменить.

- **Тема** — раздача на форумном трекере. TorrentMonitor следит за её страницей и
  скачивает torrent-файл заново, когда раздачу обновляют.
- **Сериал** — новые серии ищутся по названию в ленте трекера.

Когда записей больше пяти, над списком появляются поиск по названию, два фильтра —
по трекеру и по состоянию («С ошибками», «На паузе», «Проверка прекращена») — и выбор порядка:

| Порядок | Как расположены записи |
|---|---|
| **Сначала новые** (по умолчанию) | по дате обновления, последние сверху |
| **Сначала старые** | по дате обновления, давние сверху |
| **По названию, А→Я** | по алфавиту; числа в названии сравниваются как числа («сезон 2» раньше «сезон 10») |
| **По названию, Я→А** | в обратном порядке |

Запись, которая ещё не скачивалась, занимает место по дате добавления.

Когда записей больше пятидесяти, список показан страницами: рядом с фильтрами появляется
выбор «по 50», «по 100», «по 200» или «все», под списком — переход между страницами и счётчик
(«1–50 из 230»). Поиск и фильтры действуют на весь список, а не на одну страницу. Порядок
и размер страницы запоминаются в браузере.

Отметка **«Компактно»** рядом с кнопками показывает каждую запись одной строкой: название,
дата обновления, метки и кнопки. Кнопка со стрелкой в строке разворачивает одну запись
полностью — с трекером, категорией, связью с Sonarr и текстом ошибки. На узком экране
в строке остаются название и метки, остальное открывается стрелкой. Выбор запоминается
в браузере.

### Строка списка

- Название. У темы это ссылка на её страницу на трекере.
- Трекер; у сериала — качество и последняя серия.
- Дата последнего обновления или «ещё не скачивалась». Время показано по часам вашего
  браузера; если часы трекера другие, рядом стоит и его время («на трекере … МСК») —
  см. [Настройки](Settings#время-и-часовые-пояса).
- Категория и каталог загрузки, если они заданы.
- Связь с сериалом Sonarr, если она есть: «Sonarr: название, сезон N».
- Метки:
  - **ошибка** — последняя проверка не удалась; текст ошибки показан под строкой;
  - **пауза** — тема не проверяется, пока её не возобновят;
  - **проверка прекращена** — тема давно не обновлялась
    (см. [Настройки](Settings#прекращение-проверки-тем-без-обновлений));
  - **ждёт torrent-клиент** — torrent-файл скачан, но клиент был недоступен; файл
    будет передан при следующей проверке;
  - **трекер не поддерживается** — трекер удалён из TorrentMonitor.

Кнопки в строке:

| Кнопка | Что делает |
|---|---|
| **Проверить** | проверяет сейчас только эту тему |
| **Пауза** / **Возобновить** | останавливает и возобновляет проверку темы |
| **Изменить** | открывает форму темы |
| **Удалить** | удаляет тему из TorrentMonitor |

### Добавить тему

Кнопка **«Добавить тему»**:

- **Ссылка на тему** — адрес страницы раздачи, например
  `https://rutracker.org/forum/viewtopic.php?t=4201572`. Трекер определяется по ссылке.
- **Название** — необязательно. Если оставить пустым, оно берётся с трекера.
- **Обновлять название, когда оно меняется на трекере**.

Для трекера, которому нужна учётная запись, сначала заполните её в разделе «Трекеры»:
иначе тема не добавится, и сообщение скажет об этом.

### Добавить сериал

Кнопка **«Добавить сериал»**:

- **Трекер** — один из сериальных трекеров;
- **Название сериала** — так, как оно написано в ленте трекера (обычно английское);
- **Качество** — SD, 720p или 1080p.

Один сериал в разном качестве — это разные записи.

### Дополнительные настройки

Ссылка **«Дополнительные настройки»** в форме темы или сериала:

| Поле | Описание |
|---|---|
| **Каталог загрузки** | Куда клиент сохраняет файлы этой темы. Пусто — как в настройках. |
| **Категория** | Категория в qBittorrent. Пусто — как в настройках. |
| **Скрипт** | Путь к скрипту на сервере. Запускается после добавления раздачи в torrent-клиент. |
| **Прекращать проверку через** | Число дней без обновлений. Пусто — как в настройках, `0` — проверять всегда. |
| **Сериал в Sonarr**, **Сезон** | Только у тем: связь темы с сериалом Sonarr — см. [Интеграция с Sonarr](Sonarr-Integration#связь-своей-темы-с-сериалом). |

### Изменить

Форма та же, что при добавлении, и ещё две отметки:

- **Пауза: не проверять**;
- **Скачать заново при следующей проверке** — при следующей проверке раздача
  считается новой и скачивается снова.

### Удалить

Перед удалением интерфейс спрашивает подтверждение. Если раздача этой темы есть
в torrent-клиенте, можно отметить:

- **Удалить раздачу из torrent-клиента**;
- **…вместе со скачанными файлами**. Начальное состояние этой отметки задаёт
  настройка в [Настройки → Torrent-клиент](Settings#torrent-клиент).

## Пользователи

TorrentMonitor следит за новыми раздачами пользователя трекера. Это умеют не все
трекеры — в списке выбора только подходящие
(см. [Поддерживаемые трекеры](Supported-Trackers)).

Выберите трекер, введите имя пользователя на трекере и нажмите **«Следить»**.
Раздачи появятся после следующей проверки.

Найденные раздачи показаны под именем пользователя, новые сверху. У каждой три кнопки:

| Кнопка | Что делает |
|---|---|
| **Скачать** | раздача скачивается один раз, при следующей проверке |
| **Отслеживать** | раздача добавляется в «Торренты» и отслеживается постоянно |
| **Скрыть** | убирает раздачу из списка |

**«Скрыть все»** убирает все найденные раздачи этого пользователя.
**«Не следить»** удаляет пользователя вместе с его списком.

## Трекеры

Все трекеры на одной странице, по строке на трекер. В строке: название, тип
(«темы» или «сериалы»), число отслеживаемых записей и состояние:

| Состояние | Значение |
|---|---|
| **не настроен** | учётные данные не заданы |
| **учётная запись задана** | логин сохранён |
| **вход по cookie** | логина нет, сохранена cookie из браузера |
| **вход не нужен** | трекер работает без учётной записи |
| **ошибки: N** | у трекера есть ошибки; они перечислены в разделе «Состояние» |

Заполняйте только те трекеры, которыми пользуетесь. Нажмите на строку — откроется форма:

- **Логин** и **Пароль**. Сохранённый пароль в браузер не передаётся. Пустое поле
  «Пароль» означает «не менять».
- **Адрес** — другой адрес (зеркало) трекера. Несколько адресов через запятую:
  используется первый доступный. Пусто — адрес по умолчанию. Поле есть и у трекеров
  без учётной записи.
- **Часовой пояс** — по каким часам трекер показывает дату раздачи. «Как в общих
  настройках» — пояс из **Настройки → Общие**. Поле видно, когда в разделе «Настройки»
  включена отметка «Показать расширенные».
- **Прокси** — «Как в общих настройках», «Без прокси» или «Через прокси». Для
  последнего можно указать свой адрес и тип прокси; пустой адрес — прокси из общих
  настроек. Подробнее — [Прокси и зеркала](Proxy-and-Mirrors#прокси-только-для-одного-трекера).
- **Вход по cookie из браузера** — для трекеров, которые при входе требуют капчу
  (например, nnmclub.to). Войдите на трекер в браузере и вставьте cookie сайта
  в виде `имя=значение; имя2=значение2`. Логин и пароль тогда не обязательны.
  Отметка «Забыть сохранённую сессию» удаляет сохранённую cookie.

Кнопки:

- **Сохранить**. Сохранение сбрасывает ошибки этого трекера.
- **Сохранить и проверить вход** — сохраняет и сразу пробует войти на трекер.
  Результат показывается сообщением: «Вход на … выполнен.» или текст ошибки.
- **Сбросить ошибки** — видна, когда у трекера есть ошибки.
- **Удалить учётные данные** — удаляет логин, пароль и сохранённую
  сессию трекера. Адрес и прокси остаются. Видна, когда есть что удалять.

## Состояние

Здесь ошибки, проверка работы и запуск проверки.

- **Доступна версия …** — виден, когда вышла новая версия: описание изменений,
  кнопка **«Установить»** и ссылка на страницу выпуска. См. [Обновление](Updating).
- **Ошибки** — сгруппированы по источнику (трекер, torrent-клиент, `api`, `system`).
  У ошибки показаны время, текст и тема, к которой она относится. Ссылка «сбросить»
  убирает ошибки одного источника, кнопка «Сбросить все» — все.
- **Журнал событий** — что происходило: проверки с их итогом и названиями обновлённых тем
  («Проверено тем: 120 — обновлено 3… Обновлено: …»), обновления программы, изменения
  настроек и трекеров, добавленные и удалённые темы, проверки связи с torrent-клиентом
  и решателем. Список можно ограничить одним видом событий. Пароли и ключи в журнал
  не пишутся — только то, что они изменены. Под списком, если включён «Подробный журнал проверки», —
  сворачиваемый подробный журнал последней проверки; во время проверки он раскрыт и обновляется.

  Подробно обо всех журналах — на странице [Решение проблем](Troubleshooting#журналы).
- **Проверка работы** — что проверяется (кнопка **«Скопировать сведения»** копирует версии
  программы, PHP, torrent-клиента и решателя и основные настройки без паролей — приложите
  их к сообщению об ошибке):
  - *Сервер*: версия PHP и расширения, возможность обновления из интерфейса и
    фонового запуска, когда была последняя проверка (если больше двух суток назад —
    проверьте cron);
  - *Файлы*: права на каталог данных и каталог torrent-файлов, свободное место,
    не лежит ли каталог данных внутри каталога сайта;
  - *Сеть*: подключение к интернету, отвечает ли решатель Cloudflare;
  - *Трекеры*: доступность трекеров, которыми вы пользуетесь (есть учётные данные
    или темы), и заданы ли для них учётные данные;
  - *Torrent-клиент*: отвечает ли клиент и удался ли вход;
  - *Уведомления*: заданы ли сервис и адрес.

  Кнопка «Проверить заново» повторяет проверки.
- **Проверить обновления TorrentMonitor** — ссылка внизу страницы.

## Проверка без фонового запуска

Обычно «Проверить сейчас» запускает проверку в фоне. Для этого PHP нужны функция
`exec` и CLI-интерпретатор. Если чего-то из этого нет, проверка выполняется внутри
запроса: страница ждёт, пока она закончится. В «Состояние → Проверка работы»
об этом есть строка. Путь к CLI-интерпретатору можно задать в `config.php` —
см. [API](API#post-apirun--запустить-проверку).

## RSS-лента TorrentMonitor

Если в **Настройки → Общие** включена «RSS-лента скачанных torrent-файлов»,
TorrentMonitor отдаёт ленту по адресу `http://ВАШ_АДРЕС_ТМ/rss` — её можно
подключить к RSS-читалке или другой автоматизации.
