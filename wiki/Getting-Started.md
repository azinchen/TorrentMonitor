# Первоначальная настройка

Эта страница проведёт вас от первого запуска до первой автоматически скачанной раздачи.
Предполагается, что TorrentMonitor уже установлен —
[в Docker](Installation-Docker) или [в LAMP](Installation-LAMP).

---

## Шаг 1 — Первый запуск

Откройте адрес TorrentMonitor в браузере. Новая установка (каталог данных пуст)
показывает форму **«Настройка TorrentMonitor»** из трёх частей. Всё это можно
изменить позже в разделе «Настройки».

1. **Пароль для входа** — не короче 4 символов, вводится дважды. Пароля
   по умолчанию нет. Отметка «Не защищать паролем (доступ есть только у меня)»
   отключает вход по паролю — ставьте её, только если TorrentMonitor недоступен
   никому, кроме вас.
2. **Адрес TorrentMonitor** — подставляется из адресной строки браузера, например
   `http://192.168.1.10:8080/`. Используется в ссылках RSS-ленты и в ссылках
   на torrent-файлы.
3. **Torrent-клиент** — по желанию. «Не использовать: только сохранять torrent-файлы»
   или один из клиентов: qBittorrent, Transmission, Deluge, SynologyDS, TorrServer.
   Для клиента укажите адрес, логин и пароль (у Deluge — только пароль) и каталог
   загрузки.

Нажмите **«Начать работу»**. Вы сразу войдёте в интерфейс, откроется раздел «Трекеры».
При настройке создаётся и ключ [API](API).

Выполните настройку сразу после установки: пока она не сделана, форму увидит любой,
кто откроет адрес TorrentMonitor.

> Установка, перенесённая с версии 3.x, форму настройки не показывает: сразу
> спрашивается прежний пароль. См. [Обновление](Updating#новый-веб-интерфейс).

## Шаг 2 — Учётные данные трекеров

Большинство трекеров отдают `.torrent`-файлы только авторизованным пользователям,
поэтому TorrentMonitor должен заходить на трекер под вашей учётной записью.

Откройте раздел **Трекеры** и нажмите на строку нужного трекера. Укажите логин и
пароль и нажмите **«Сохранить и проверить вход»** — TorrentMonitor попробует войти
и сообщит результат. Заполняйте только те трекеры, которыми пользуетесь. Особенности
отдельных трекеров описаны в [списке трекеров](Supported-Trackers).

- Если основной адрес трекера у вас не открывается, укажите в поле «Адрес» его зеркало,
  например `https://rutracker.net`
  (см. [Прокси и зеркала](Proxy-and-Mirrors#другой-адрес-трекера-зеркало)).
- Если трекер при входе требует капчу, используйте «Вход по cookie из браузера»
  (см. [Веб-интерфейс](Web-Interface#трекеры)).

## Шаг 3 — Подключить торрент-клиент (по желанию)

Если клиент не был указан на шаге 1: **Настройки → Torrent-клиент** → отметьте
«Передавать скачанные torrent-файлы в torrent-клиент», выберите клиент, укажите его
адрес, логин, пароль и каталог загрузки. Кнопка **«Сохранить и проверить подключение»**
сразу покажет, отвечает ли клиент.
Подробности по каждому клиенту — на странице [Торрент-клиенты](Torrent-Clients).

Если клиент не подключать, TorrentMonitor будет просто складывать свежие
`.torrent`-файлы в каталог `torrents/` — их можно забирать оттуда любым способом.

## Шаг 4 — Добавить первую раздачу

### Тема (форумные трекеры: rutracker, kinozal, nnmclub и др.)

Раздел **Торренты** → **«Добавить тему»**:

- **Ссылка на тему** — адрес страницы раздачи,
  например `https://rutracker.org/forum/viewtopic.php?t=4201572`.
- **Название** — необязательно: если оставить пустым, оно берётся с трекера.
- В «Дополнительных настройках» — свой каталог загрузки, категория qBittorrent,
  скрипт и срок, после которого проверка прекращается. Всё необязательно.

Когда в теме обновят торрент (например, добавят новую серию), TorrentMonitor скачает
новый `.torrent`, удалит из клиента старую раздачу и добавит новую.

### Сериал (сериальные трекеры: lostfilm.tv, lostfilm-mirror, newstudio.tv)

Раздел **Торренты** → **«Добавить сериал»**: выберите трекер, введите название
сериала так, как оно написано в ленте трекера (обычно английское, например
`House of the Dragon`), и качество (SD / 720p / 1080p). TorrentMonitor будет ловить
новые серии в ленте трекера.

### Пользователь

Раздел **Пользователи**: выберите трекер, введите имя пользователя и нажмите
«Следить». Новые раздачи этого пользователя появятся здесь же после следующей
проверки; каждую можно скачать один раз, поставить на постоянное отслеживание или
скрыть.

## Шаг 5 — Проверить работу

- Кнопка **«Проверить сейчас»** (справа вверху на любой странице) запускает проверку
  вручную, не дожидаясь расписания. Кнопка «Проверить» в строке темы проверяет
  только её. В Docker проверка выполняется по cron автоматически, по умолчанию раз
  в час; в LAMP — по заданному вами crontab.
- Раздел **Состояние**: ошибки (неверный пароль трекера, трекер недоступен), журнал
  последней проверки и блок «Проверка работы» — сервер, файлы, сеть, трекеры,
  torrent-клиент, уведомления.
- Раздел **Торренты** — список отслеживаемых раздач и их состояние.
