# Установка в Docker

Рекомендуемый способ установки TorrentMonitor — готовый Docker-образ
[**alfonder/torrentmonitor**](https://hub.docker.com/r/alfonder/torrentmonitor).
Внутри контейнера уже есть всё необходимое: веб-сервер, PHP и планировщик —
ничего устанавливать и настраивать на хосте не нужно. Базы данных нет: данные хранятся
в JSON-файлах.

> Docker-образ — отдельный проект
> [torrentmonitor-dockerized](https://github.com/alfonder/torrentmonitor-dockerized),
> который развивает и поддерживает [**Александр Фомичёв** (alfonder)](https://github.com/alfonder) —
> он не входит в состав TorrentMonitor. Спасибо Александру за контейнеризацию проекта!
> Вопросы по самому контейнеру (образ, теги, переменные окружения) задавайте
> в его репозитории.

Минимальный запуск:

```bash
docker run -d \
  --name torrentmonitor \
  --restart unless-stopped \
  -p 8080:80 \
  -v tm_torrents:/data/htdocs/torrents \
  -v tm_db:/data/htdocs/db \
  alfonder/torrentmonitor
```

Откройте `http://IP_СЕРВЕРА:8080`. Новая установка показывает форму настройки: пароль
для входа (или работа без пароля), адрес TorrentMonitor и, по желанию, torrent-клиент.
Пароля по умолчанию нет. Заполните форму сразу: пока она не заполнена, это может сделать
любой, кто откроет этот адрес. Дальше вся работа идёт в веб-интерфейсе:
[Первоначальная настройка](Getting-Started).

Оба тома обязательно сохраняйте. Том `db` — это каталог данных: в нём лежат JSON-файлы
(`config.json`, `torrents.json`, `state.json`) с темами, учётными данными и настройками.
Пароли трекеров и torrent-клиента записаны в `config.json` в открытом виде — не давайте
доступ к этому тому посторонним. В `torrents` — скачанные `.torrent`-файлы.

## Обновление с версии 3.x

Тома и параметры запуска остаются прежними. Сделайте копию тома `db`, обновите образ
и пересоздайте контейнер. При первом запуске контейнер сам переносит данные
из прежней базы (`tm.sqlite`) в JSON-файлы и пишет результат в лог (`docker logs torrentmonitor`).
Темы, учётные данные трекеров, настройки и пароль веб-интерфейса сохраняются; форма
настройки не показывается. Прежние файлы (`tm.sqlite`, `config.xml`, `db_crypt.key`)
остаются в томе как копия и больше не используются.

Подробно — в вики Docker-проекта:
[Updating-and-Maintenance](https://github.com/alfonder/torrentmonitor-dockerized/wiki/Updating-and-Maintenance).
Общий порядок перехода — на странице [Обновление](Updating#переход-с-версии-3x).
