# История изменений

## 4.0.0

Первая версия, которую развивает [azinchen/TorrentMonitor](https://github.com/azinchen/TorrentMonitor).
Программа переписана; данные прежних версий переносятся. Порядок перехода — в вики, страница
«Обновление».

**Что нужно сделать при переходе с 3.x**

- Перенести данные из базы: `php tools/convert-db.php` (один раз).
- Направить веб-сервер на каталог `public/`.
- Нужен PHP 8.0 или новее. База данных больше не нужна. Расширение iconv больше не нужно
  (хватает mbstring), поэтому на Alpine не требуется собирать GNU libiconv.

**Хранение данных**

- Настройки, темы и состояние лежат в JSON-файлах в каталоге данных. MySQL, PostgreSQL и SQLite
  не используются.
- Файлы данных подходят любой версии программы: новая версия только добавляет поля, прежняя
  сохраняет то, чего не знает. После возврата на предыдущую версию данные остаются рабочими.
- Программа, настройки и данные недоступны из браузера: корень сайта — каталог `public/`.
- Файлы данных, их копии `*.bak` и файл проверки обновлений доступны только пользователю
  программы (и группе, если каталог данных настроен для двух пользователей).

**Трекеры**

- Трекеры за Cloudflare работают и с FlareSolverr, и с Byparr: вход, страницы тем и скачивание
  torrent-файлов.
- У трекера можно указать другой адрес (зеркало); у LostFilm есть запасные адреса.
- Вход по cookie из браузера для трекеров, которые требуют капчу.
- Кнопка «Удалить учётные данные» у трекера: убирает логин, пароль и сохранённую сессию.
- nnmclub.to и booktracker.org: дата раздачи находится и при изменённой разметке страницы;
  booktracker.org берёт cookie сессии `bb_data`.
- kinozal: если адрес записи не отвечает, пробуются другие адреса трекера. Домен kinozal.tv больше
  не работает, темы под этой записью проверяются через kinozal.me и kinozal.guru.
- riperam.org открывается по https.
- rustorka.com открывается по https; его собственная капча при входе распознаётся и объясняется в ошибке.
- Убраны casstudio.tk, hamsterstudio.org, tfile.cc и baibako.tv: эти сайты больше не отвечают.

**Проверка**

- Два запуска одновременно не работают; без интернета трекеры не опрашиваются.
- Часовые пояса: «сегодня» и «вчера» на странице трекера считаются по часам трекера, а не
  сервера (раньше на сервере в другом поясе раздача kinozal и anidub могла скачаться повторно).
  Пояс трекеров задаётся в настройках (по умолчанию московский), у трекера может быть свой.
  В списке тем время показано по часам браузера и по часам трекера.
- Когда трекер не отвечает, в ошибке и на странице «Состояние» сказано, в чём дело: не отвечает
  прокси или сам трекер (адрес не найден, нет ответа, отказ в соединении, ошибка TLS).
- `php engine.php --tracker=…`, `--topic=…`, `--dry-run`.
- Тему, которая давно не обновлялась, можно перестать проверять автоматически.

**Torrent-клиенты**

- qBittorrent, Transmission и Deluge получают torrent-файл напрямую, без ссылки на TorrentMonitor.
- При удалении темы можно удалить раздачу и скачанные файлы.
- qBittorrent: если он сбросил сеанс (так бывает, когда рядом работает Sonarr), вход повторяется.
- Synology Download Station: номер задачи определяется только по ссылке раздачи, чужая задача
  больше не может быть удалена при обновлении.

**Sonarr**

- Webhook отвечает сразу, работает с qBittorrent, Transmission и Deluge, сохраняет каталог и
  категорию раздачи, не считает ошибкой уже отслеживаемую тему и остальные события.
- По желанию удаляет темы сериала, когда сериал удалён в Sonarr.
- По желанию удаляет прежнюю тему сезона (и отдельной настройкой — её раздачу), когда Sonarr
  загружает этот сезон целиком другой раздачей.
- Тему, добавленную вручную, можно связать с сериалом Sonarr (название сериала и сезон):
  тогда она заменяется и удаляется вместе с сериалом так же, как темы, добавленные Sonarr.

**Веб-интерфейс**

- Новый интерфейс: Торренты, Пользователи, Трекеры, Настройки, Состояние. Светлая и тёмная темы,
  работает на телефоне, не загружает файлы с других сайтов.
- Первоначальная настройка при первом запуске; пароля по умолчанию больше нет.
- Список тем можно показать компактно: каждая тема одной строкой.
- Все трекеры на одной странице, с проверкой входа. Проверка подключения к torrent-клиенту и
  пробное уведомление.
- Журнал последней проверки и проверка работы на странице «Состояние».
- Раздела «Новости» больше нет: о новой версии сообщают строка вверху интерфейса, блок
  на странице «Состояние» и уведомление.

**API**

- Имена полей темы изменены: `torrent_id` → `topicId`, `hd` (`0`, `1`, `2`) → `quality`
  (`sd`, `720`, `1080`), `ep` → `episode`, `timestamp` → `updatedAt`, `auto_update` → `autoRename`,
  `pause` → `paused`. Логические значения стали настоящими `true`/`false` (были `0`/`1`).
- Новые поля темы: `url`, `stopAfterDays`, `addedAt`, `lastActivityAt`, `stopped`. Список и одна
  тема возвращают одинаковый набор полей.
- В `GET /api/errors` поля переименованы: `reason` → `code`, `tracker` → `source`, `id` → `topic`.

**Обновления**

- Новые версии берутся из GitHub Releases этого репозитория. Обновление удаляет файлы прежней версии.
